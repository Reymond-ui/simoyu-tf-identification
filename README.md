# Simoyu Transfer Function Identification

GUI-инструмент для идентификации передаточной функции по переходному процессу методом Симою. На вход — запись ступенчатого воздействия и отклика системы (CSV или ROS bag), на выход — числитель и знаменатель `W(s)` и график сравнения с исходным сигналом.

## Что делает

1. Загружает `time / cmd / data` из файла.
2. Находит участок, где командный сигнал принимает максимальное значение — это и есть ступенька.
3. Нормирует отклик на амплитуду ступеньки и оценивает запаздывание по нулевым отсчётам.
4. Восстанавливает коэффициенты передаточной функции заданного порядка методом Симою.
5. Строит отклик модели на ступеньку рядом с реальным переходным процессом и показывает невязку `|Δy|`.

## Возможности

- Чтение `.csv` (три столбца `time;cmd;data`) и ROS `.bag` (топики `cmd` / `data`)
- Автопоиск ступеньки и запаздывания
- Настраиваемый порядок числителя (`M_ORDER`) и знаменателя (`N_ORDER`)
- Визуализация переходного процесса, отклика модели и невязки
- Отдельная утилита `crop.py` — вырезает фрагмент записи по времени и сохраняет его как CSV с обнулённым временем

## Структура

| Файл | Назначение |
|------|-----------|
| `main.py` | Основное приложение: чтение, идентификация, GUI |
